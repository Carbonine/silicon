Settings

Appearance

Theme
Choose how Silicon looks. System follows your device.
Show bookmarks bar
A row of your bookmarks under the address bar. It only appears when you have bookmarks. Ctrl+Shift+B turns it on and off.

Search engine

Search engine used in the address bar
Used when what you type isn't a web address.
Custom search address
Write the address of your search engine and put %s where your search should go, for example example.com/?q=%s. Without %s it won't work.

Panic key

Enable panic key
Pressing the key immediately stops everything and sends this tab to the panic site. Works on every page, including sites you're browsing. Off by default.
Panic key
Click the button, then press the key or combination you want. Unbound by default. Esc cancels.
Panic site
Where you're sent. Must be an http(s) address.
Open in about:blank
Opens Silicon in a new about:blank window and sends this tab to the panic site. Allow pop-ups if your browser blocks it. Your open tabs don't carry over.
Open in blob:
Same as above, but the new window uses a blob: address.
Auto cover
The first time you press a key on the front page (new tab), it opens in about:blank and this tab goes to the panic site. Mouse clicks don't count, and typing in Settings doesn't trigger it. Off by default.

Tab cloak

Tab cloak
When this window loses focus, the tab title and icon change to look like this site. Each icon is loaded from the site itself.
Always show cloak
Keep the cloak on even while you're using Silicon, not only when the window loses focus. Off by default.
Icon address
Required. The full web address of the icon image, for example https://example.com/favicon.ico. Silicon doesn't look icons up for you.
Custom title
Required. The tab title to show. The custom cloak only works once both the title and the icon address are set.

History

Save browsing history
Keep a list of the pages you open, shown on silicon://history. It stays in this browser. Turning this off doesn't delete what's already saved.

Leaving

Confirm before leaving
Ask before this tab is closed or reloaded. The panic key ignores this. Off by default.

Proxy

Transport
How proxied traffic leaves the Wisp server. Epoxy is the default; libcurl is an alternative that supports an upstream proxy.
Proxy games
Load games from their own servers (like Selenite) through the proxy, which helps when those sites are blocked. Games hosted by Silicon are never proxied, and emulator games load directly for now because they don't run through the proxy. You can switch any game with the shield button in the player.
Wisp server
WebSocket address of the Wisp server. Leave empty to use the one built into this server.
Upstream proxy
Optional SOCKS5 or HTTP proxy for the transport, e.g. socks5h://localhost:9050 for Tor. Requires the libcurl transport.
Reset proxy settings
Restore the transport, Wisp server and upstream proxy to their defaults.

Backup

Export data
Download everything Silicon has saved (settings, bookmarks, history, favorites, recently played, and games' local storage) as one JSON file. Saves that games keep in IndexedDB aren't in it; see Game saves below. It may include your panic key and site, so keep it private.
Import data
Restore from a backup file. This replaces your current settings and data. Only import files you exported yourself.

Game saves

Export game saves
Download the saves games keep in this browser (their local storage and IndexedDB data) as a file. The backup above only covers local storage, so use this for games that keep saves in IndexedDB.
Import game saves
Put saves from a file back into this browser. Saves with the same name are replaced; everything else is kept. Close any open game tabs first. Only import files you exported yourself.

Danger zone

Clear data
Deletes your shortcuts, browsing history, favorites, recently played, saved game data, and cached proxy data (cookies and site storage). Your settings are kept. This can't be undone.
Reset all settings
Puts every setting back to its default (theme, search engine, privacy options, panic key, proxy). Your data is kept. This can't be undone.
